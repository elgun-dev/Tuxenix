# Screenshot record

`installer-network-2026-10-22.png` is an unmodified 1440 × 900 screenshot
from the October 22 release workspace's final-image QEMU preview. It shows
the installer Network page with virtual Ethernet connected and no wireless
adapter detected. It is used in the installation walkthrough to explain
that a guest may expose Ethernet even when the host uses Wi-Fi.

The capture predates the later installer redesign. It does not show that
unreleased interface or establish physical Wi-Fi support.
